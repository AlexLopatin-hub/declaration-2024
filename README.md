# Парсер для приложения Декларация 2024

Данный скрипт/программа в автоматическом режиме находит клиентов, имеющих остаток по налоговому вычету 3-НДФЛ и сводит их контакты в одну таблицу.

Программа позволяет:
1. Считывать данные из формата dc4.
2. Парсить xml, созданные программой Декларация 2024.
3. Хранить считанные данные в локальной базе данных с возможностью последующего экспорта в текстовый файл.

## Технологии

*   **Язык:** Python.
*   **Среда разработки:** PyCharm.
*   **Библиотеки:** Pywinauto, Tkinter, Sqlite3.
